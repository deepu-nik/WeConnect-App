# WeConnect 📱

### A College-Focused Social & Academic Mobile Application

> A mobile platform designed for college students to connect, communicate, share academic resources, and stay updated with what's happening around their college community.

---

## 📌 About the Project

**WeConnect** is a college-focused mobile application built to create a dedicated digital space for students.

The idea is to bring several student-oriented features together in one application — including communication, academic resource sharing, student updates, profiles, and community interaction.

The project was created as a learning and development project to explore **mobile application development, Firebase integration, authentication, navigation, data management, and real-world application architecture**.

---

## 🎯 Why I Built This

College students often use multiple platforms for different purposes — messaging, sharing study material, discovering events, and communicating with other students.

I wanted to explore the idea of a **single college-focused platform** where students could:

* Connect with other students
* Communicate with each other
* Share study resources
* Post college-related updates
* Discover what's happening around their college
* Maintain their student profile

The project also gave me an opportunity to learn how a real mobile application is structured and developed.

## ✨ Features

### 👤 Student Profiles

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/deepu-nik/WeConnect-App.git
```

### 2. Navigate to the project

```bash
cd WeConnect-App
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the Expo development server

```bash
npx expo start
```

You can then run the application using an emulator, simulator, or a compatible mobile device through Expo.
